# ClearTrack

### Faculty Clearance Management System

Xavier University – Ateneo de Cagayan

ClearTrack is a Progressive Web Application (PWA) developed to digitize and streamline the faculty clearance process of Xavier University – Ateneo de Cagayan. The system provides a centralized platform for faculty members, approvers, assistant approvers, and administrators to manage, monitor, and process faculty clearances. It supports both desktop and mobile views for convenient access across devices.

## Overview

ClearTrack aims to make the faculty clearance process more organized, efficient, and transparent by replacing manual processes with a centralized digital workflow. The system uses role-based access, providing users with features and permissions appropriate to their responsibilities.

## User Roles

* Faculty Member – Submits and monitors clearance status.
* Approver – Reviews and processes assigned clearance requests.
* Assistant Approver – Assists approvers in processing clearance requests.
* System Administrator – Manages users, roles, and system functions.
* Analytics Administrator – Monitors clearance data and analytics.

## Key Features

### Faculty Clearance Management
Allows faculty members to submit, manage, and monitor their clearance status in one platform.

### Digital Approval Workflow
Enables approvers and assistant approvers to review and process clearance requests digitally.

### Role-Based Access
Provides different features and permissions based on the user's assigned role.

### Analytics and Reporting
Provides clearance-related data and analytics to help administrators monitor the overall clearance process.

## Progressive Web Application
ClearTrack is designed as a Progressive Web Application, providing a responsive experience across different devices.

* Desktop view
* Mobile view
* Responsive interface
* Web-based access

## Installation

1. Clone the repository:

```bash
git clone https://github.com/[username]/[repository-name].git
```

2. Navigate to the project directory:

```bash
cd [repository-name]
```

3. Install the frontend dependencies:

```bash
npm install
```

4. Configure the required environment variables.

5. Build and start the application using Docker Compose:

```bash
docker compose -f compose.prod.yml up -d --build
```

6. Check the status of the running containers:

```bash
docker compose -f compose.prod.yml ps
```

7. Access the application through the configured application URL.
